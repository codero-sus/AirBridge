# Airbridge

Airbridge Mobile is a Flutter/Dart implementation of an Airbridge LAN mesh node. The mobile/desktop application runs its own HTTP + WebSocket gateway, UDP-broadcast peer discovery, encrypted message spool, and responsive dashboard.

See [`airbridge_mobile/README.md`](airbridge_mobile/README.md) for the architecture and [`airbridge_mobile/build_instructions.md`](airbridge_mobile/build_instructions.md) for Android APK, Windows, Linux, macOS, and iOS build/deployment steps.
